# hope-kb

This is the system knowledge repository for Hope.

It holds:

- director profiles
- committee definitions
- prompt templates
- visual language vocabulary
- camera work vocabulary
- continuity rules
- transition vocabulary
- export templates

The app consumes a validated read-only snapshot of this repo.
