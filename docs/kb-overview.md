# hope-kb Overview

`hope-kb` is the authoritative system knowledge source for Hope.

## v0.1 target contents

- 7 director profiles
- committee presets
- scene affinity matrix
- handoff rules
- Chinese visual language terms
- Chinese camera work vocabulary
- continuity rules
- export templates

## Snapshot rule

The app does not edit this repo at runtime.
It consumes validated read-only snapshots bundled with releases.
