# 导演参考索引 v0.1

这份索引专门服务 `director_profiles` 和导演 few-shot 的复核。

它的目的不是证明“风格结论绝对正确”，而是保证：

- 每位导演都有可追溯的公开锚点
- 团队归纳出来的风格字段，能回指到代表作品
- 后续补充 `director_scene_affinity`、`committee_handoff_rules` 时，有基础参照

## 使用规则

- `director_profiles` 里的风格字段仍然属于 `team_distillation`
- 但每位导演都必须至少能回指到这里列出的 1 组以上公开锚点
- 后续扩写 few-shot、scene affinity、handoff rules 时，优先从这里的代表作品出发
