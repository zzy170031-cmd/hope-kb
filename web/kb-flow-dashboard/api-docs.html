Hope-KB API 接入文档

5179 本地控制台用于手动搜索候选、生成确认包、写入 KB，并产出 PWA 可消费的 summary-only adapter。
返回入库流程

接入边界

服务端 env 管密钥 确认前只写 draft 人工确认后才入库 PWA 只消费 summary-only

这个 dashboard 不是 PWA 主流程，也不是图谱浏览器。它只增强现有链路：reviewed_wiki -> wiki-to-runtime mapping -> runtime KB snapshot -> PWA adapter output。

服务端环境

  • 默认自动读取桌面 hope-kb-search.env。
  • 也可以用 HOPE_KB_SEARCH_ENV_FILE 指定 env 文件。
  • 前端不会读取、保存或提交 API Key。
  • 包文件只记录 provider、model、base_url_host、credential_state、web_search 和状态原因。

推荐 env

HOPE_KB_SEARCH_PROVIDER=qwen
HOPE_KB_SEARCH_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
HOPE_KB_SEARCH_ENDPOINT=/chat/completions
HOPE_KB_SEARCH_MODEL=qwen3.6-plus
HOPE_KB_SEARCH_KEY=你的 DashScope API Key
HOPE_KB_ENABLE_SEARCH=true
HOPE_KB_SEARCH_TIMEOUT_MS=30000

  "title": "即梦国漫动作分镜提示词提升",
  "search_focus": "seedance_anime_prompt"

确认包请求体

POST /api/intake/:run_id/confirm
Content-Type: application/json

{
  "accepted_reviewed_wiki_ids": [
    "rw-seedance2-storyboard-field-discipline"
  ]
}

PWA 同步接口

GET  /api/pwa/status
POST /api/pwa/sync

同步只复制 summary-only adapter 输出到 PWA latest.json，并运行 Hope-KB adapter check 与 PWA kbAdapter 测试。

状态字段

package.status:
  request_recorded
  sources_collected
  screened
  recommendations_ready
  confirmed_package
  applied_to_kb
  failed

搜索状态

package.search_plan.search_provider_status:
  status: live_search | model_search | model_fallback | fixture_fallback
  reason:
    ok
    missing_credential
    live_search_timeout
    live_search_failed
    live_search_timeout_model_ok
    live_search_failed_model_ok
    no_url_bound_candidates

落盘证据

package.artifacts:
  draft_package
  confirmed_package
  reviewed_wiki
  wiki_to_runtime_mapping
  runtime_snapshot
  pwa_adapter_output
