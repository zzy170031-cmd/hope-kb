          关联规则

          实线是应用产出路径；虚线是手动搜索入库路径；用户确认只允许写入已审知识。

          运行边界

          本地需求 0，等待用户手动发起。

          21 个应用场景

          API 接入文档

          5179 控制台只负责搜索候选、确认包和 KB 写入门禁；密钥只从服务端 env 读取。

          服务端环境

          • 默认读取桌面 hope-kb-search.env，也可用 HOPE_KB_SEARCH_ENV_FILE 指定。
          • 必需：HOPE_KB_SEARCH_KEY、HOPE_KB_SEARCH_MODEL、HOPE_KB_SEARCH_BASE_URL。
          • 兼容 PWA 变量：HOPE_WEB_API_KEY、HOPE_TEXT_MODEL_API_KEY。
          • 前端不会读取或存储 API Key，包文件只记录 provider、model、host 和状态。

          入库边界

          • 开始搜索只写 draft package，不写 reviewed_wiki。
          • 必须先生成 confirmed package，才能调用 apply 写入 KB。
          • 写入只通过 apply-confirmed-intake-package.js 执行。
          • PWA 只消费 summary-only adapter 输出，不读取 raw KB、来源正文或密钥。

          接口顺序

          GET /api/intake/latest GET /api/provider/status POST /api/provider/test GET /api/pwa/status POST /api/pwa/sync POST /api/intake/start POST /api/intake/:run_id/sources POST /api/intake/:run_id/screen POST /api/intake/:run_id/recommendations POST /api/intake/:run_id/confirm POST /api/intake/:run_id/apply

          最小请求

          POST /api/intake/start Content-Type: application/json { "title": "即梦国漫动作分镜提示词提升", "search_focus": "seedance_anime_prompt" }

          确认包请求体

          POST /api/intake/:run_id/confirm Content-Type: application/json { "accepted_reviewed_wiki_ids": [ "rw-seedance2-storyboard-field-discipline" ] }

          PWA 同步

          GET /api/pwa/status POST /api/pwa/sync

          同步接口只把 samples/pwa-kb-adapter-output.sample.json 复制到 PWA 的 latest.json，并运行 adapter check 与 PWA 测试。

          关键返回字段

          package.status: request_recorded | sources_collected | screened | recommendations_ready | confirmed_package | applied_to_kb | failed package.search_plan.search_provider_status: status: live_search | model_search | model_fallback | fixture_fallback reason: ok | missing_credential | live_search_timeout | live_search_failed | live_search_timeout_model_ok package.artifacts: draft_package confirmed_package reviewed_wiki wiki_to_runtime_mapping runtime_snapshot pwa_adapter_output
