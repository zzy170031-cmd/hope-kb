# seed

This directory stores the importable seed bundle for `hope-kb`.

## Layout

- `v0.1-seed-manifest.md`
  - 人读版首批种子说明
- `v0.1/source_register.json`
  - 机器可读的来源登记表
- `v0.1/*.json`
  - 各类种子记录
- `director-profiles/`
- `prompt-templates/`
- `vocabulary/`
- `story-structure/`
- `export-templates/`
  - 对应的录入说明与后续扩量说明

## Rule

- `manifest.json` 决定导入顺序
- `source_register.json` 决定来源登记
- 所有种子默认中文主字段
